# Código de conducta

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En resumen: se discuten ideas, no personas. Se agradece la crítica con fuentes, también
cuando desmonta un resultado del proyecto. Hablamos de una enfermedad que afecta a
personas reales: ni promesas de cura ni consejos médicos en *issues* o PR.

Para informar de un comportamiento inaceptable, abre un *issue* privado o escribe al
mantenedor a través de su perfil de GitHub.
